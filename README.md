# Middeniye Dhammasena Thero — Portfolio

Static portfolio built with HTML, CSS and vanilla JavaScript.

## GitHub Pages
1. Repository Settings → Pages.
2. Under Build and deployment choose **Deploy from a branch**.
3. Select **main** and **/(root)**, Save.
4. Website: https://nightowl-vpn.github.io/DK-OFC-/

## Personal images
Create an `assets` folder and upload your logo as `md-logo.png` and portrait as `profile.jpg`. The HTML already references these paths. If omitted, the layout still works but those image spots will be blank.
